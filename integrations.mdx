## Git Repository Syncing

Sync your Git repository with Shalostx to keep documentation live.

### Prerequisites
- GitHub or GitLab account
- Repository with Markdown files in `docs/` folder

<Steps>
  <Step title="Connect Repository" icon="git-branch">
    In Shalostx dashboard, navigate to `Integrations > Git Sync`.

    Select your provider and authorize access.
  </Step>
  <Step title="Configure Sync Path">
    Set source path to `docs/` and branch to `main`.
  </Step>
  <Step title="Enable Auto-Sync">
    Toggle `Auto-sync on push` and save.

````bash
# Example Git push that triggers sync
git add docs/introduction.md
git commit -m "Update intro"
git push origin main
````

  </Step>
</Steps>

## Webhook Configurations

Set up webhooks to receive Shalostx events like doc publishes or edits.

<CodeGroup tabs="Node.js,Python,cURL">
  ```javascript
  const express = require('express');
  const app = express();
  app.use(express.json());

  app.post('/shalostx-webhook', (req, res) => {
    console.log('Event:', req.body.event);
    console.log('Doc ID:', req.body.data.id);
    res.status(200).send('OK');
  });

  app.listen(3000);
  ```
  ```python
  from flask import Flask, request, jsonify
  app = Flask(__name__)

  @app.route('/shalostx-webhook', methods=['POST'])
  def webhook():
      data = request.json
      print(f"Event: {data['event']}")
      print(f"Doc ID: {data['data']['id']}")
      return jsonify({'status': 'OK'}), 200

  if __name__ == '__main__':
      app.run(port=3000)
  ```
  ```bash
  curl -X POST https://your-webhook-url.com/shalostx-webhook \
    -H "Content-Type: application/json" \
    -d '{
      "event": "doc.published",
      "data": {"id": "doc-123", "title": "New Guide"}
    }'
  ```
</CodeGroup>

Add your webhook URL in Shalostx dashboard under `Integrations > Webhooks`.

## API Access for Custom Integrations

Build advanced integrations using Shalostx REST API at `https://api.shalostx.com/v1`.

<ParamField path="docs/:id" param-type="GET" required="true">
  Retrieve a specific document.
</ParamField>

<ParamField header="Authorization" param-type="string" required="true">
  Bearer `{YOUR_API_KEY}`.
</ParamField>

<Request tabs="cURL,JavaScript">
  ```bash
  curl https://api.shalostx.com/v1/docs/doc-123 \
    -H "Authorization: Bearer YOUR_API_KEY"
  ```
  ```javascript
  const response = await fetch('https://api.shalostx.com/v1/docs/doc-123', {
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY'
    }
  });
  const doc = await response.json();
  ```
</Request>

<Response tabs="200">
  ```json
  {
    "id": "doc-123",
    "title": "Integrations Guide",
    "content": "Markdown content here...",
    "updated_at": "2024-10-15T10:00:00Z"
  }
  ```
</Response>

<Callout kind="info">
  Generate your API key from `Account > API Keys`. Store it securely.
</Callout>
