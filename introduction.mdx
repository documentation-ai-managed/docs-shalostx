## Overview

Shalostx provides a centralized hub for your project documentation. You create, organize, and publish docs effortlessly, keeping teams aligned. Customize layouts, embed media, and collaborate in real-time to streamline your workflow.

<Callout kind="info">
Shalostx supports Markdown, MDX, and integrates with Git for version control.
</Callout>

## Quick Navigation Guide

Get up and running quickly with these steps.

<Steps>
  <Step title="Sign Up" icon="user-plus">


  <Step title="Create Project" icon="plus">

## Brand Guidelines

Follow these guidelines to maintain consistency when customizing Shalostx.

### Color Palette

| Color Name | Hex Code     | Usage                  |
|------------|--------------|------------------------|
| Primary    | `#3B82F6`   | Buttons, links, accents |
| Secondary  | `#1E40AF`   | Headings, borders      |
| Neutral    | `#F8FAFC`   | Backgrounds            |
| Danger     | `#EF4444`   | Errors, alerts         |

<Tabs>
  <Tab title="CSS Variables" icon="code">
    Define brand colors in your theme configuration.

    <CodeGroup tabs="CSS,SCSS">
      ```css
      :root {
        --primary-color: #3B82F6;
        --secondary-color: #1E40AF;
      }

      .button {
        background-color: var(--primary-color);
        color: white;
      }
      ```
      ```scss
      $primary: #3B82F6;
      $secondary: #1E40AF;

      .button {
        background-color: $primary;
        color: white;
      }
      ```
    </CodeGroup>
  </Tab>
  <Tab title="Component Usage" icon="package">
    Apply colors to Shalostx components.

    ```jsx
    <Card title="Example" icon="star" style={{ '--accent': '#3B82F6' }}>
      Branded card content.
    </Card>
    ```
  </Tab>
</Tabs>

<Expandable title="Advanced Theming Tips" default-open="false">
  Override default styles by injecting custom CSS. Target classes like `.doc-header` for precise control.

  <Callout kind="tip">
    Test themes in preview mode before publishing.
  </Callout>
</Expandable>
