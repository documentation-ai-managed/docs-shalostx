## Migration Guide

<Callout kind="alert">
  Review breaking changes before updating. Backup your workspace first.
</Callout>

Follow these steps to migrate to the latest version:

<Steps>
  <Step title="Backup Workspace" icon="database">
    Export your current site:
    
````bash
shalostx export --workspace my-project > backup.tar.gz
````
    
  </Step>
  <Step title="Update CLI" icon="download">
    Install the latest version using your package manager.
    
    <CodeGroup tabs="npm,yarn">
````bash
npm install shalostx@latest
````
````bash
yarn add shalostx@latest
````
    </CodeGroup>
  </Step>
  <Step title="Reconfigure" icon="settings">
    Update your config file. Replace deprecated options:
    
````yaml
# Old (v1.0.0)
legacyConfig: true

# New (v1.2.0+)
newConfig:
  enableRealtime: true
  themeColor: "#3B82F6"
````
    
  </Step>
  <Step title="Deploy" icon="rocket">
    Redeploy your site:
    
````bash
shalostx deploy --prod
````
  </Step>
</Steps>

<Expandable title="Detailed Migration Notes" default-open="false">
