## Document Creation and Editing

Create new documents directly in your Shalostx workspace. You access the editor via the dashboard or API for automated workflows.

<Steps>
  <Step title="Create a New Document" icon="plus">
    Navigate to your workspace and click **New Document**.

    Choose a template like "API Reference" or start blank.
  </Step>
  <Step title="Edit with MDX" icon="edit">
    Use the live MDX editor for headings, code blocks, and components.

````mdx
## Welcome

This is your first document.

```javascript
console.log("Hello, Shalostx!");
```
````
  </Step>
  <Step title="Preview and Publish" icon="eye">
    Preview changes in real-time, then publish to make it live.
  </Step>
</Steps>

Integrate via API for programmatic creation:

<CodeGroup tabs="JavaScript,cURL">
  ```javascript
  const response = await fetch('https://api.example.com/v1/documents', {
    method: 'POST',
    headers: { 'Authorization': `Bearer ${YOUR_API_KEY}` },
    body: JSON.stringify({
      title: 'My New Doc',
      content: '# Hello World'
    })
  });
  ```
  ```bash
  curl -X POST https://api.example.com/v1/documents \
    -H "Authorization: Bearer YOUR_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{"title":"My New Doc","content":"# Hello World"}'
  ```
</CodeGroup>

## Organization with Folders and Tags

Organize documents using folders for hierarchy or tags for cross-referencing.

<Tabs>
  <Tab title="Folders" icon="folder">
    Create nested folders to mirror your project structure.

    | Action       | Description                  |
    |--------------|------------------------------|
    | Create Folder| Right-click workspace > New Folder |
    | Move Doc     | Drag document to folder      |
    | Rename       | Edit folder properties       |

    Folders support unlimited nesting for complex projects.
  </Tab>
  <Tab title="Tags" icon="tag">
    Apply tags like `api`, `guide`, or `deprecated` for filtering.

    <ParamField path="tags" param-type="array" required="false">
      Array of strings for categorization.
    </ParamField>

    Combine with search for dynamic organization.
  </Tab>
</Tabs>

## Collaboration and Sharing

Invite collaborators with role-based access: viewer, editor, or admin. Generate shareable links with optional passwords.

<Callout kind="tip">
  Use public links for read-only access and protected links for teams.
</Callout>

Track edits in real-time with @mentions and comments.

## Search and Version History

Search across all documents with full-text indexing. Filter by tags, folders, or date.

<Expandable title="Version History Details" default-open="true">
  Access history via document settings:

  - View diffs between versions
  - Restore previous states
  - Export change logs

  Every edit creates a snapshot, retained for 90 days.
</Expandable>

<ResponseField name="versions" field-type="array">
  Array of version objects with timestamps and authors.
</ResponseField>
