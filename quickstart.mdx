## Prerequisites

Before you begin, ensure you have:

- A valid email address for account registration
- Access to a modern web browser like Chrome or Firefox
- Optional: A GitHub account for content import

<Callout kind="info">

Shalostx works best with browsers supporting ES6+. Disable ad blockers if you encounter issues.

</Callout>

## Sign Up and Log In

Create your Shalostx account in under a minute.

<Steps>
  <Step title="Visit the Dashboard" icon="monitor">
    Navigate to `https://app.shalostx.com` and click **Sign Up**.
  </Step>
  <Step title="Enter Your Details" icon="user">
    Provide your email, create a strong password, and verify via the confirmation link sent to your inbox.
  </Step>
  <Step title="Log In" icon="log-in">
    Return to `https://app.shalostx.com/login` and sign in with your credentials.
  </Step>
</Steps>

## Create Your First Documentation Space

Once logged in, set up a new space for your project docs.

<Steps>
  <Step title="Click New Space" icon="plus">
    From the dashboard, select **New Documentation Space**.
  </Step>
  <Step title="Configure Basics" icon="settings">
    Enter a name like `My Project Docs`, add a description, and choose visibility (public or private).
  </Step>
  <Step title="Publish Space" icon="rocket">
    Click **Create**. Your space is now live at `https://app.shalostx.com/spaces/my-project-docs`.
  </Step>
</Steps>

## Import Initial Content

Bring in your existing docs using these methods.

<Tabs>
  <Tab title="Markdown Files" icon="file-text">
    Upload local files or paste content.

    <Steps>
      <Step title="Drag and Drop">
        Drag `.md` or `.mdx` files into the file tree.
      </Step>
      <Step title="Create Page">
        Click **New Page** and paste Markdown.
      </Step>
    </Steps>

````markdown
# Welcome to My Docs

This is your first page.

- Feature 1
- Feature 2
````
  </Tab>
  <Tab title="GitHub Repo" icon="github">
    Connect your repository directly.

    <Callout kind="tip">

    Grant read access to `https://github.com/yourusername/project-docs`.

    </Callout>

````bash
# Example repo structure
docs/
├── introduction.mdx
├── quickstart.mdx
└── api.mdx
````
  </Tab>
  <Tab title="API Import" icon="zap">
    Use the import API for automation.

    ```javascript
    const response = await fetch('https://api.shalostx.com/v1/spaces/import', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${YOUR_API_KEY}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        spaceId: 'your-space-id',
        source: 'github://yourusername/project-docs'
      })
    });
    ```
  </Tab>
</Tabs>
