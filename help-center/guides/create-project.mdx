## Overview

This guide shows you how to set up a new project in Shalostx.

<Steps>
  <Step title="Go to Your Dashboard">
    ````
    Visit https://dashboard.shalostx.com and sign in.
    ````
  </Step>
  <Step title="Start a Project">
    ````
    Click the "New Project" button on the dashboard.
    ````
  </Step>
  <Step title="Fill in Details">
    ````
    Enter your project name and optional description. Click "Create".
    ````
  </Step>
  <Step title="Begin Writing">
    ````
    Use the editor to add and organize your documentation content.
    ````
  </Step>
</Steps>
