## Getting Started

To begin a new documentation project in Shalostx:

1. Log in to your Shalostx account.
2. From the dashboard, click "New Project".
3. Enter your project name and description.
4. Click "Create" to set up your workspace.

Your project is now ready! You can start adding and organizing documentation using the Shalostx editor. All changes are saved automatically.
